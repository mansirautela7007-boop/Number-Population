# Audio credits

Every file here is **CC0 (public domain)** from OpenGameArt.org: free to use,
change and ship, with no attribution required. The credits are kept anyway, as
thanks and so the source of each file can be traced. The files were converted
to AAC (`.m4a`) for size; nothing else was changed.
